# Decisions

- Target normal companies, not token projects.
- Focus V1 only on X content creators.
- Use USDC instead of arbitrary project tokens.
- Price approved work by official impressions, not flat post fees.
- Accrue earnings off-chain and settle in public Solana batches.
- Require campaign funding before submissions open.
- Keep unused campaign budget refundable.
- Charge a configurable 2% platform fee during confirmed creator settlement.
- Do not use MagicBlock, private payments, AI, or a custom Solana program in V1.
- Learn from competitor workflows without copying their source, brand, or text.

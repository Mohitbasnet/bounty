# Micro-Earning Model

“Micropayment” describes how creator entitlement grows, not one blockchain
transaction per view.

- Official X snapshots update verified impressions.
- Only complete reward blocks accrue.
- An unlock prevents tiny low-quality submissions from earning.
- A creator cap controls campaign exposure.
- Accrued balances are settled in practical public USDC batches.

This preserves real-time feedback without creating excessive Solana
transactions or transaction fees.
